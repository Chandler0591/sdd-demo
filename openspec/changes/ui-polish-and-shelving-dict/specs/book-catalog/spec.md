# Spec Delta

## ADDED Requirements

### Requirement: Select multi-level book category
图书编目与检索的分类选择 MUST 展示「图书分类」字典树的全部后代分类，任一层级分类均可被选中；新增/编辑表单与检索筛选均以树形结构展示分类层级，避免同名歧义。

#### Scenario: 树形选择深层分类
- **WHEN** 分类字典存在三级结构（如 图书分类 → 文学 → 小说），管理员在新增图书表单中选择分类
- **THEN** 树形下拉展开展示「文学」及其子分类「小说」等全部后代节点，深层分类可被选中并保存

#### Scenario: 树形筛选深层分类
- **WHEN** 管理员在图书检索表单以树形下拉展开并选中某个深层分类筛选
- **THEN** 系统返回该分类下的全部图书

### Requirement: New book enters shelving queue
新书录入（含重复 ISBN 数量叠加）MUST 进入待上架清单：可借数量为 0、待上架数量等于新增馆藏量；上架确认后恢复可借。待上架图书不可办理借出。

#### Scenario: 新书录入后出现在待上架清单
- **WHEN** 管理员录入一本新书（含重复 ISBN 数量叠加）
- **THEN** 该书可借数量为 0，出现在待上架清单中，直到上架确认后恢复可借

#### Scenario: 待上架图书不可借出
- **WHEN** 管理员在借还办理中查询到一本待上架图书（可借 0 册）
- **THEN** 系统标识「待上架，暂不可借」，借出按钮不可用
