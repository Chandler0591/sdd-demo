# Spec Delta

## ADDED Requirements

### Requirement: Choose shelving location from dictionary
上架确认时，书架位置 MUST 从系统字典「书架位置」的任意层级子项中选择（树形展示全部后代），系统记录所选位置的完整路径名（自根逐级拼接，如「A 区 1 排 01 号」）作为该次上架的位置与图书当前位置。

#### Scenario: 树形选择深层书架位置
- **WHEN** 管理员在待上架清单中对图书办理上架确认，且「书架位置」字典存在多级结构（区 → 排 → 号）
- **THEN** 位置字段以树形下拉展示全部后代节点，任意层级可选中，提交后上架记录与图书当前位置使用所选位置的完整路径名

#### Scenario: 字典无位置项时无法上架
- **WHEN** 「书架位置」字典下不存在任何子项，管理员提交上架确认
- **THEN** 系统拒绝提交并提示补充书架位置

### Requirement: Upload photo returns accessible web path
上架照片上传成功后，系统 MUST 返回可经 /uploads/** 静态访问的 Web 路径（/uploads/<文件名>），该路径可直接用于前端图片预览，上架记录存储该路径。

#### Scenario: 上传后照片可预览
- **WHEN** 管理员上传一张现场照片
- **THEN** 系统返回以 /uploads/ 开头的路径，前端按该路径请求可获取照片内容并展示预览

### Requirement: Search reader and book in loan desk
借还办理时，读者查找 MUST 支持按借书证号精确匹配或按姓名模糊匹配，图书查找 MUST 支持按 ISBN 精确匹配或按书名模糊匹配；模糊匹配返回多个结果时，管理员可从候选中选择。

#### Scenario: 按姓名模糊查找读者
- **WHEN** 管理员在借还办理页输入读者姓名关键字查询，且存在多个姓名匹配的读者
- **THEN** 系统列出匹配的读者供选择，选中后展示其在借记录

#### Scenario: 按书名模糊查找图书
- **WHEN** 管理员在借还办理页输入书名关键字查询，且馆藏存在多本标题匹配的图书
- **THEN** 系统列出匹配的图书供选择，选中后可办理借出

#### Scenario: 精确匹配优先
- **WHEN** 管理员输入的借书证号或 ISBN 与馆藏记录精确一致
- **THEN** 系统直接命中对应读者或图书，无需从候选列表选择

### Requirement: Batch shelving confirm
上架确认 MUST 支持一次处理多册图书：本次上架数量在 1 至待上架数量之间（缺省为全部待上架数量），确认后待上架数量按本次数量扣减、可借数量同步增加，上架记录带本次上架册数与服务端时间戳；超出待上架数量时拒绝。

#### Scenario: 一次上架多册
- **WHEN** 某图书待上架 10 册，管理员选择位置与照片并将本次上架数量设为 10
- **THEN** 一次确认后待上架数量归 0、可借数量 +10，图书移出待上架清单，上架记录记载本次上架 10 册与上架时间

#### Scenario: 本次数量超出待上架数量被拒绝
- **WHEN** 管理员提交的本次上架数量大于该图书待上架数量
- **THEN** 系统拒绝提交并提示数量不得超过待上架数量

### Requirement: Shelving records page
上架办理页 MUST 提供「上架记录」页签：按上架时间倒序分页展示每次上架记录（图书书名 / ISBN / 书架位置 / 本次上架册数 / 现场照片 / 操作人 / 上架时间），支持按书名与操作人模糊筛选，用于考核整理效率与读者定位。

#### Scenario: 查看上架记录
- **WHEN** 管理员打开上架办理页的「上架记录」页签
- **THEN** 系统按上架时间倒序分页展示全部上架记录，每条含书名、ISBN、位置、本次册数、现场照片、操作人与上架时间

#### Scenario: 按书名或操作人筛选记录
- **WHEN** 管理员输入书名或操作人关键字检索上架记录
- **THEN** 系统仅返回书名或操作人模糊匹配的记录，仍按上架时间倒序分页展示
