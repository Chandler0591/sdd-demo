# Spec Delta

## Purpose

管理界面的交互体验能力，定义页签式菜单导航与页面状态保留、列表页工具栏布局等前端体验约定。

## ADDED Requirements

### Requirement: Tab-based menu navigation
系统 SHALL 以页签形式组织已打开的菜单页面：切换菜单打开对应页签，页签可关闭；已打开页面的查询条件、列表数据与表单状态在页签切换后 MUST 保留。

#### Scenario: 切换页签保留页面数据
- **WHEN** 管理员在图书管理页录入检索条件并查看结果后，切换到其他菜单再切回
- **THEN** 图书管理页仍保留原检索条件与列表结果

#### Scenario: 关闭页签
- **WHEN** 管理员关闭当前激活的页签
- **THEN** 系统移除该页签并切换到剩余页签，全部关闭后内容区为空白

### Requirement: List page toolbar
列表页的新增类操作（新增图书、注册读者、新增分类）SHALL 位于表格上方的工具栏区域，与检索表单分离。

#### Scenario: 工具栏操作入口
- **WHEN** 管理员打开图书管理、读者管理或字典管理页面
- **THEN** 表格上方工具栏提供对应的新增操作按钮，点击后打开表单弹窗
