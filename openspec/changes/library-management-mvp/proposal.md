# Proposal

## Why

图书馆目前依靠手工台账管理图书、读者与借阅记录，效率低、易出错，且无法快速查询馆藏与借阅状态。本变更搭建一套 Web 化的图书管理系统 MVP，实现「图书编目 — 读者管理 — 借阅流通」的核心闭环，为后续扩展（续借、预约、罚款等）奠定基础。

## What Changes

- 新增图书编目管理：图书信息（书名、ISBN、作者、分类等）的新增、编辑、删除与多条件检索，跟踪馆藏库存数量。
- 新增读者管理：读者档案的注册、编辑、注销与查询。
- 新增借阅流通：办理借出、归还，查询当前借阅记录，自动识别超期未还。
- 新增图书上架流程：归还后图书进入待上架状态不可借，上架确认时记录书架位置与现场照片（带时间戳），用于整理人员考核与读者定位。
- 新增系统字典：以 code / name / pcode 树形结构统一维护字典数据（如图书分类），业务表单的枚举取值统一从字典引用。
- 新增一个 Web 全栈应用：浏览器端管理界面 + REST API 后端服务。
- 数据库使用 MySQL 8 持久化存储，所有表主键为字符串类型雪花 ID。
- 本 MVP 仅面向管理员（馆员）操作，读者自助登录、查询等功能留作后续变更。

## Capabilities

### New Capabilities
- `book-catalog`: 图书编目管理能力——图书元数据的维护、库存跟踪与检索。
- `reader-management`: 读者管理能力——读者档案的注册、维护与查询。
- `circulation`: 借阅流通能力——借出、归还办理与借阅状态、超期追踪，以及归还图书的上架确认与位置记录。
- `system-dictionary`: 系统字典能力——字典项的统一维护与业务表单引用。

## Impact

- 全新项目（greenfield）：新建前端管理界面、后端服务与数据库 schema。
