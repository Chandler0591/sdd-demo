# Spec Delta

## Purpose

为借阅者与工作人员提供微信小程序端能力：查询书籍信息与所在位置、按借书证号查询当前在借书籍、工作人员拍照识别书籍信息并录入馆藏。

## ADDED Requirements

### Requirement: Search book with location
借阅者在小程序 MUST 能按书名或 ISBN 查询书籍信息，结果包含书名、作者、分类、可借数量与所在位置（未上架显示待上架）。

#### Scenario: 按书名查询到书籍
- **WHEN** 借阅者输入书名关键字查询，馆藏存在匹配的图书
- **THEN** 系统返回匹配图书列表，每本展示书名、作者、分类、可借数量与所在位置

#### Scenario: 查询无匹配结果
- **WHEN** 借阅者输入的关键字没有任何图书匹配
- **THEN** 系统提示未找到相关图书

### Requirement: Query borrowed books by card number
借阅者在小程序 MUST 能按借书证号查询自己当前在借的书籍，结果包含书名、借出时间、应还时间与逾期标识，便于及时归还。

#### Scenario: 查询到在借书籍
- **WHEN** 借阅者输入有效的借书证号查询
- **THEN** 系统返回该读者当前未归还的书籍列表，每本展示书名、借出时间、应还时间，应还时间已过期的标记为逾期

#### Scenario: 借书证号不存在
- **WHEN** 借阅者输入的借书证号在系统中不存在
- **THEN** 系统提示借书证号无效

#### Scenario: 无在借书籍
- **WHEN** 借阅者查询的读者当前没有在借书籍
- **THEN** 系统提示当前无在借书籍

### Requirement: Staff photo recognition and catalog entry
工作人员在小程序 MUST 能拍照上传书籍照片，系统识别提取书名、作者与 ISBN 供确认，确认后录入馆藏并进入待上架清单。

#### Scenario: 拍照识别并确认录入
- **WHEN** 工作人员拍照上传书籍照片，系统识别返回书名、作者与 ISBN，工作人员确认信息
- **THEN** 图书录入馆藏并进入待上架清单，待上架数量为录入数量

#### Scenario: 识别信息不完整时人工修正
- **WHEN** 系统识别返回的信息不完整或错误
- **THEN** 工作人员可手工修改书名、作者与 ISBN 后提交录入

#### Scenario: 识别失败
- **WHEN** 系统无法从照片识别出书籍信息
- **THEN** 系统提示识别失败，工作人员可重新拍照或改为手工录入
