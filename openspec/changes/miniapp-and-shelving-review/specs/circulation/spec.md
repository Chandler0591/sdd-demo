# Spec Delta

## ADDED Requirements

### Requirement: Shelving review gate
上架确认后图书 MUST 进入「待审核」状态且不可借出；审核通过后图书才恢复可借；审核驳回后图书退回待上架清单。借还办理 MUST 拒绝借出待审核图书。

#### Scenario: 上架确认后进入待审核
- **WHEN** 管理员对上架图书提交上架确认（位置与照片）
- **THEN** 图书进入待审核状态，可借数量不增加，借还办理不可借出该图书

#### Scenario: 审核通过恢复可借
- **WHEN** 审核人在 PC 端对待审核图书点击通过
- **THEN** 图书可借数量按本次上架数量增加，图书恢复可借，审核记录记载审核人与审核时间

#### Scenario: 审核驳回退回待上架
- **WHEN** 审核人对待审核图书点击驳回
- **THEN** 图书退回待上架清单，本次上架数量重新计入待上架数量，可重新办理上架确认

### Requirement: Shelving review list
PC 端上架办理页 MUST 提供「待审核」页签，展示待审核图书的上架信息（书名、位置、现场照片、本次上架册数、操作人、上架时间），并提供通过与驳回操作。

#### Scenario: 查看待审核清单
- **WHEN** 管理员打开上架办理页的「待审核」页签
- **THEN** 系统按上架时间倒序展示全部待审核图书及其上架信息

#### Scenario: 待审核清单随审核变化
- **WHEN** 图书审核通过或驳回
- **THEN** 该图书从待审核清单移除，审核结果反映到图书可借状态或待上架清单
